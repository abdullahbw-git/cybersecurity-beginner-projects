
# Phishing Email Detector

## Project Overview

A beginner-friendly Python cybersecurity project
that identifies common phishing indicators in
email messages.

## Features

- Suspicious phrase detection
- URL extraction
- URL shortener detection
- IP address hostname detection
- HTTP link detection
- Basic risk scoring
- LOW, MEDIUM and HIGH classification
- Security analysis report

## Technologies Used

- Python 3
- Regular Expressions
- urllib.parse
- ipaddress

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python phishing_detector.py

## Risk Classification

- LOW: 0–19
- MEDIUM: 20–49
- HIGH: 50–100

## Learning Outcomes

- Python programming
- Email security
- Phishing indicators
- URL analysis
- Basic threat detection
- Security reporting

## Limitations

This is a basic rule-based educational tool.

It does not authenticate senders, inspect attachments,
or check live threat intelligence.

A LOW score does not guarantee an email is safe.
