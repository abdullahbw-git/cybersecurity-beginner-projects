
# Localhost Port Scanner

## Project Overview

A beginner-friendly Python TCP port scanner
that checks selected ports on the local computer.

## Features

- Checks selected TCP ports
- Identifies open ports
- Identifies closed ports
- Displays common service names
- Generates a terminal scan report

## Technologies

- Python 3
- Socket Programming
- TCP/IP Networking


## How to Run

Open the project directory in VS Code.

Run:

python port_scanner.py

## Learning Outcomes

- Understanding TCP ports
- Understanding TCP connections
- Learning Python socket programming
- Understanding localhost
- Basic network security monitoring

## Safety

It is intended for educational and defensive
cybersecurity learning.

## Limitation

An open port does not automatically mean
a security vulnerability exists.
